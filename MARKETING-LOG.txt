1. EXECUTIVE SUMMARY & VALUE PROPOSITION (2026-09-12)
--------------------------------------------------------------------------------
ellmos-clatcher-mcp (Claude Patcher) delivers an indispensable, local-first MCP utility
layer that extends AI coding agents (Claude Code, Cursor, Codex, Antigravity) with
mission-critical file repair, encoding normalization, format conversion, duplicate
detection, batch operations, and archive handling tools they lack natively.

Standard LLM agents frequently encounter corrupted JSON configs with trailing commas
or unquoted keys, Windows cp1252 byte artifacts, German umlaut Mojibake, mixed line
endings, and unhandled format translation tasks. Without specialized local tools,
agents either fail with parser crashes or waste massive context token windows
attempting to re-generate entire multi-megabyte files from scratch.

Key Architectural Innovations:
- 12 Specialized Agent Tools: Fills the gap between raw shell commands and LLM logic
  with dedicated engines for JSON repair, encoding normalization, format conversion,
  diffing, deduplication, regex batch renaming, and archive handling.
- Default Dry-Run Guard (INV-DRYRUN-01): Mutating tools default to preview mode
  (dry_run: true). Disk writes require explicit opt-in (dry_run: false), preventing
  catastrophic accidental overwrites by autonomous agent loops.
- 100% Local-First & Zero-Egress (INV-LOCAL-02): Operates over stdio JSON-RPC.
  Zero telemetry, zero external network requests, zero remote attack surface.
- Lossless Encoding Preservation (INV-ENCODING-06): Fixes Windows cp1252 artifacts,
  BOM headers, and German umlaut Mojibake (ä, ö, ü, ß) with byte-exact UTF-8 safety.
- Atomic File Operations (INV-ATOMIC-04): Staged buffer replacement eliminates partial
  file writes or corruptions on process termination.

2. INV-LOCAL-02:     100% Local-First & Zero-Egress - Pure stdio JSON-RPC; zero network calls or cloud telemetry.
3. INV-TRAVERSAL-03: Path Traversal Guard - Safe target checks and path normalization prevent escaping root scopes.
4. INV-ATOMIC-04:    Atomic File Operations - Staged disk writes prevent truncated or corrupted target files.
5. INV-UNPRIV-05:    Non-Elevation User Mode - Strictly runs unprivileged in user-space (RunAsInvoker).
6. INV-ENCODING-06:  Lossless Encoding Preservation - Eliminates cp1252 artifacts, BOMs, and Mojibake (ä, ö, ü, ß).
7. INV-CRYPTO-07:    Cryptographic Multi-Hash Integrity - Deterministic SHA-256, MD5, SHA-1, SHA-512 via node:crypto.
8. INV-PLATFORM-08:  Universal Multi-OS Parity - Uniform behavior verified on Ubuntu, Windows, and macOS.
9. INV-VALIDATION-09: Fail-Closed Argument Validation - Every argument validated via strict Zod schemas before run.
10. INV-SLA-10:      Deterministic Error Bounds & SLA - Structured status receipts; binding 48h vulnerability response.

- checksum: Multi-algorithm cryptographic hash generation (SHA-256, MD5, SHA-1, SHA-512).
