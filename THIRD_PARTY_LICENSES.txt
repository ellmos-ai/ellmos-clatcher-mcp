## Level 1 SBOM Invariant Verification (Stand: 2026-10-01)

All 10 architectural and runtime governance invariants are confirmed:
- INV-DRYRUN-01: Default Dry-Run Guard (Mutating tools default to dry_run: true; writes require explicit dry_run: false)
- INV-LOCAL-02: 100% Local-First & Zero-Egress (Stdio JSON-RPC transport guarantees complete air-gapped isolation; zero external telemetry)
- INV-TRAVERSAL-03: Path Traversal Guard (Filesystem operations validate target path boundaries against directory traversal)
- INV-ATOMIC-04: Atomic File Operations (Modifying pipelines write to isolated temporary buffers before replacement)
- INV-UNPRIV-05: Non-Elevation User-Mode (Runs strictly in user space as RunAsInvoker; zero administrative elevation required)
- INV-ENCODING-06: Lossless Encoding Preservation (Reversible UTF-8 normalization eliminates cp1252 artifacts and German umlaut Mojibake)
- INV-CRYPTO-07: Cryptographic Multi-Hash Integrity (Native collision-resistant digest calculation SHA-256, MD5, SHA-1, SHA-512)
- INV-PLATFORM-08: Universal Multi-OS Parity (Bit-level identical behavior across Linux, Windows, and macOS environments)
- INV-VALIDATION-09: Fail-Closed Argument Validation (All tool calls are validated against strict Zod runtime schemas before execution)
- INV-SLA-10: Binding 30d Remediation SLA (Structured status receipts with diff previews, binding 48-hour response, 5 business days triage, and 30 calendar days remediation SLA)
